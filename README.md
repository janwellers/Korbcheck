# Korbcheck

Einkaufskorb-Preisvergleich für Aldi, Lidl, Kaufland, Rewe und Edeka.

- **Aldi**: Live-Regalpreise aus dem Online-Sortiment von Aldi Süd
- **Rewe**: Live-Regalpreise des nächsten Rewe-Markts zur Postleitzahl
- **Alle Märkte**: aktuelle Prospekt-Angebote (marktguru) zur Postleitzahl
- Ohne Live-Preis: klar markierte Schätzung

Start: `npm start` (Node 20+, keine Abhängigkeiten) → http://localhost:3000

Preise werden im Server zwischengespeichert (Regalpreise 6 h, Angebote 3 h).
